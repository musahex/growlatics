## Method
Every check gets one status: PASS (verified behaviour, not just code exists), FAIL, MISSING, NOT APPLICABLE (with reason), PENDING VERIFICATION (needs production, an account, owner approval or field data). Every FAIL/MISSING: routes, files, exact issue, evidence + repro, impact, priority, recommended fix, auto-fixable?, fixed?, post-fix verification. Priorities: P0 launch blocker (security/privacy exposure, accidental production noindex, broken critical conversion, invalid production routing), P1 high, P2 medium, P3 low. Label each check as source inspection / local export test / public preview check / production-only.
